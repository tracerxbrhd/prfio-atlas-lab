Methodology & sources

Atlas Lab uses a local, authored dataset of 20 illustrative city scenarios. The values are not official statistics and the project does not calculate an overall city score.

Project documentation

  • Methodology — indicator interpretation and comparison limits.
  • Data reference — record schema, ranges, filtering and CSV export.
  • Accessibility — keyboard interaction and chart alternatives.

Visualization references

  • Observable Plot — interactions
  • Observable — interactive scatterplots

These references informed interaction research only. Atlas Lab renders its map, scatterplot and radar chart with project-owned native SVG code.

Assets

The schematic map geometry and interface icons are local project assets. System fonts are used; the application does not load external fonts or third-party imagery.

Scope

Coordinates locate city centres for the schematic projection. Population figures use non-standardised illustrative urban-area boundaries, and indicator values should not be used for relocation, investment or policy decisions.
