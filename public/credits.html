Media and typography

Charts and map geometry are authored SVG rendered from local data. The compass and interface icons are original line SVGs. The map is schematic, not a geographic reference.

System fonts; no external font service.

Icons

Original SVG alternatives are included. Selected Flaticon reference: Flaticon — Compass. Automated licensed downloading was unavailable; no Flaticon file is distributed.

Technology

React 19, Vite, native SVG charts, JavaScript, CSS, ESLint, Prettier and Playwright.

Scope

Indicator values are illustrative scenarios, not official statistics or a ranking. Population boundaries are not standardised. The interface documents these limits and calculates no composite score. Comparisons and filters reset on reload.
