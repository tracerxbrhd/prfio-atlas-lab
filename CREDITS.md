## Icons

Selected reference: [Flaticon — Compass](https://www.flaticon.com/free-icon/compass_10504964). The Flaticon page requires attribution for downloaded assets. An authenticated asset download/licensing flow was unavailable in the automated environment. This project ships independently authored, consistent SVG alternatives. No Flaticon source file is redistributed. Replace only after obtaining the appropriate licence and adding the author attribution supplied by Flaticon.

## Local media

Charts and map geometry are authored SVG rendered from local data. The compass and interface icons are original line SVGs. The map is schematic, not a geographic reference.
